二、教学目标

知识目标

  1. 理解 Spring Boot 的核心特性：自动配置、起步依赖、内嵌 Tomcat、约定优于配置。
  2. 掌握 Spring Boot 标准项目结构（src/main/java、src/main/resources、src/test、pom.xml、启动类位置）。
  3. 掌握 Maven 依赖管理机制：pom.xml 结构、坐标三元素（groupId/artifactId/version）、常用 starter 依赖。
  4. 掌握 application.yml 配置文件的写法（端口、上下文路径、数据源占位）。
  5. 理解启动类 @SpringBootApplication 注解与 SpringApplication.run 方法的作用。
  6. 掌握使用 Spring Initializr / IDEA 创建 Spring Boot 项目的完整流程。

能力目标

  1. 能够独立使用 IntelliJ IDEA 创建一个 Spring Boot 项目骨架。
  2. 能够阅读和修改 pom.xml，正确添加 / 排除依赖。
  3. 能够编写启动类、application.yml，并成功启动项目看到启动 Banner。
  4. 能够排查常见的 Spring Boot 启动报错（端口占用、依赖缺失、JDK 版本不符、包结构错误）。
  5. 能够对比传统 SSM 与 Spring Boot 项目结构，说明 Spring Boot 的简化之处。

素质目标（课程思政）

  1. 体会"自主可控与开源生态"——Spring Boot 简化了开发，国产开源框架（MyBatis-Plus、Knife4j）在 Java 生态中做出了重要贡献，激发学生对国产开源的认同感与参与意愿。
  2. 培养"约定优于配置"的工程思维——遵循行业规范能减少不必要的决策成本。
  3. 建立"独立动手搭建项目"的工程师自信——从"看老师搭"到"自己搭得起来"。

四、项目任务或案例任务

贯穿项目任务：搭建 CTTS 后端项目骨架

本次课任务：

  1. 教师演示使用 Spring Initializr 创建 CTTS 后端项目骨架（项目名 ctts，groupId com.ctts，artifactId ctts，包名 com.ctts）。
  2. 学生跟做：在 IDEA 中创建 Spring Boot 项目，选择 JDK 17 + Spring Boot 3.x，勾选 Spring Web、Spring Boot DevTools、Lombok。
  3. 配置 pom.xml（添加/校验 starter-web、starter-test 依赖）。
  4. 编写启动类 CttsApplication，配置 application.yml（端口 8080、上下文路径 /api）。
  5. 启动项目，浏览器访问 http://localhost:8080/api 看到 404（说明上下文路径生效，无对应接口）即视为骨架搭建成功。
  6. 编写一个最简单的 /hello 接口验证 Web 依赖生效（接口编写细节第 4 次课详讲，本次只验证可启动）。

项目背景对齐：

项目 内容
项目名 ctts（Campus Training Task System）
groupId com.ctts
artifactId ctts
包名 com.ctts（启动类位于 com.ctts.CttsApplication）
JDK 17
Spring Boot 3.x（3.2 / 3.3 均可）
构建工具 Maven
端口 8080
上下文路径 /api

📌 本次课重点是"搭起来 + 跑起来"，让学生体验 Spring Boot 的"开箱即用"。接口开发、数据库连接在后续课程展开。

五、课堂互动设计

互动 1：开场提问（5 分钟）

项目 内容
互动问题 "上节课我们讲了 HTTP 与 RESTful，大家知道一个 Java 后端接口要跑起来，最底层需要什么？如果让你从零搭一个 Java Web 项目，你会想到哪些步骤？"
组织方式 自由发言，教师板书关键词
预期学生输出 提到"Tomcat""配置""依赖""jar 包""web.xml"等关键词
教师点评要点 引出"传统方式需要装 Tomcat、配 web.xml、拷贝一堆 jar 包"的痛点，自然过渡到 Spring Boot 的"内嵌 Tomcat + 自动配置 + 起步依赖"

互动 2：代码阅读对比（讲解 K3-1、K3-2 后，10 分钟）

项目 内容
互动任务 教师屏幕展示两份项目结构截图：① 传统 SSM 项目（Spring + Spring MVC + MyBatis，含 web.xml、applicationContext.xml、spring-mvc.xml、mybatis-config.xml 等大量 XML）；② Spring Boot 项目（零 XML，只有 pom.xml + application.yml + 启动类）
组织方式 同桌两人一组，2 分钟讨论："传统 SSM 项目要写哪些配置文件？Spring Boot 把它们简化成了什么？"
预期学生输出 能识别 web.xml、applicationContext.xml；能发现 Spring Boot 没有 XML；能注意到 application.yml 替代了多个配置文件
教师点评要点 强调"约定优于配置"——Spring Boot 把"约定"内置，开发者只需配置"例外"。引出自动配置原理（面试考点伏笔）

互动 3：面试题导入（讲解 K3-5 后，5 分钟）

项目 内容
互动问题 "Spring Boot 的自动配置原理是什么？"
组织方式 教师抛出问题，不要求学生立即答出，先记下来；教师给出"线索版"答案：@EnableAutoConfiguration → spring.factories / AutoConfiguration.imports → @Conditional 条件装配
预期学生输出 学生可能答出"自动配置""少写配置文件"等浅层理解
教师点评要点 这是 Spring Boot 最高频面试题之一，本课不要求深挖原理（后续模块会讲），但要知道"自动配置 = 根据类路径下的依赖自动装配 Bean"，并记住 @SpringBootApplication 是个组合注解

六、课程思政融入点

项目 内容
融入点 自主可控与开源生态——Spring Boot 简化了 Java 开发，而国产开源框架在 Java 生态中贡献突出
技术关联 MyBatis-Plus（国产，增强 MyBatis，本课程第 5~6 次课使用）、Knife4j（国产，增强 Swagger，本课程第 11 次课使用）、Sa-Token（国产认证框架）、Hutool（国产工具库）、Druid（阿里开源连接池）
引导问题 "大家打开 Maven 中央仓库会发现，很多 Java 项目用的不是美国公司出的库，而是中国开发者/公司开源的。为什么国产开源能在中国乃至全球 Java 生态中占有一席之地？"
预期价值目标 激发学生对国产开源的认同感与自豪感，鼓励学生关注并参与国产开源社区，理解"自主可控"不是封闭而是"有自己能掌控的技术栈"

思政自然融入，不空喊口号。通过 MyBatis-Plus、Knife4j 等学生即将使用的国产框架，让学生在用的时候体会到国产开源的实力。

七、课堂练习或随堂测验

随堂练习（5 分钟，讲解结束前进行）

判断题（口头快速作答）：

  1. Spring Boot 项目必须单独安装 Tomcat 才能运行。（✗，内嵌 Tomcat）
  2. pom.xml 中的坐标三元素是 groupId、artifactId、version。（✓）
  3. @SpringBootApplication 是一个组合注解，包含自动配置功能。（✓）
  4. application.yml 必须放在 src/main/java 目录下。（✗，应放在 src/main/resources）

详细题目与解析见 题库.md。此处仅作课堂快速互动，不计分。

随堂实操验证（穿插在演示中）

教师在演示创建项目后，请 1~2 名学生上台复述创建步骤（不要求操作，只要求说出步骤顺序），教师纠正遗漏。

八、课后任务

  1. 实操（必做）：按 教学资料.md 第 3 节"项目创建流程"独立创建 CTTS 后端项目骨架，截图提交：① 项目结构树；② 启动成功日志（含 Banner）；③ 浏览器访问 http://localhost:8080/api/hello 的返回结果。
  2. 阅读：通读同文件夹 教学资料.md，重点理解自动配置原理、pom.xml 坐标、启动类注解。
  3. 思考：用自己的话（200 字内）说明"约定优于配置"在 Spring Boot 中的体现，下次课抽查。
  4. 面试题准备：整理"Spring Boot 的自动配置原理""@SpringBootApplication 注解的作用"两道题的答案要点（下次课课前抽查 2 人）。
  5. 拓展（选做）：访问 https://start.spring.io 体验网页版 Spring Initializr；阅读 Spring Boot 官方文档"Using Spring Boot"章节。
