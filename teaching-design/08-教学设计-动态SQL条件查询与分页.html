二、教学目标

知识目标

  1. 掌握 MyBatis 动态 SQL 标签 <if>、<where>、<foreach>、<choose>/<when>/<otherwise>、<set> 的作用与使用场景。
  2. 理解 <where> 标签自动处理首个 AND/OR 的原理，<set> 标签自动去除末尾逗号的原理。
  3. 掌握 MyBatis-Plus 条件构造器 QueryWrapper 的链式调用方法：eq、like、in、between、ge、le、orderByDesc 等。
  4. 理解 LambdaQueryWrapper 的类型安全特性，能用方法引用（Task::getTitle）替代字符串字段名。
  5. 掌握 MyBatis-Plus 分页插件 MybatisPlusInterceptor + PaginationInnerInterceptor 的配置；理解 Page 对象（current/size）、selectPage 方法、IPage 返回结果（records/total/pages）。

能力目标

  1. 能根据业务需求编写含 <if>/<where>/<foreach> 的 XML 动态 SQL，正确处理多条件查询。
  2. 能使用 QueryWrapper 与 LambdaQueryWrapper 实现等值、模糊、范围、IN、排序等条件查询。
  3. 能独立配置 MyBatis-Plus 分页插件并实现分页查询接口，正确返回 records/total/pages 结构。
  4. 能根据给定 XML 动态 SQL 与不同参数，分析最终生成的 SQL 语句。
  5. 能为 CTTS 系统实现任务列表多条件查询 + 分页接口。

素质目标（课程思政）

  1. 树立"以用户为中心"的设计理念——分页与条件查询让系统更好用，提升用户体验。
  2. 培养工程严谨性——动态 SQL 中 AND/OR 处理、分页参数边界、SQL 注入防范等细节决定系统稳定性。
  3. 培养技术选型与对比能力——理解 MyBatis 原生动态 SQL 与 MyBatis-Plus 条件构造器的差异与适用场景。

四、项目任务或案例任务

贯穿项目任务：CTTS 任务列表多条件查询 + 分页接口

本次课任务：

  1. 教师演示 CTTS 中"任务列表查询"的真实场景：用户在页面上选择项目、状态、输入标题关键字、点击分页——后端如何根据这些可选条件生成正确的 SQL？
  2. 学生跟随教师实现两个版本的代码：
    • 版本 A（XML 动态 SQL）：用 <if>/<where>/<foreach> 编写 TaskMapper.xml 多条件查询。
    • 版本 B（MyBatis-Plus）：用 LambdaQueryWrapper + Page 实现相同功能。
  3. 配置 MyBatis-Plus 分页插件，测试分页查询返回结构。

任务背景（详见 教学资料.md 综合示例）：

  • 业务需求：任务列表页支持按项目 ID、任务状态、标题模糊查询，并支持分页（每页 10 条）。
  • 涉及表：task（任务表）。
  • 接口设计：GET /api/tasks?page=1&size=10&projectId=1&status=进行中&title=Java。

📌 本节课是 M3 模块的关键课，将第 7 次课的"单条 CRUD"扩展到"多条件动态查询 + 分页"，是企业项目中最常见的需求。

六、课程思政融入点

项目 内容
融入点 用户体验——分页与条件查询让系统更好用，体现"以用户为中心"的设计理念
技术关联 没有分页时一次性返回上万条数据，前端卡顿、数据库压力巨大；没有条件查询时用户无法精准定位数据。这两个功能是后端"为用户着想"的典型体现
引导问题 "你用过淘宝、京东的商品列表吗？为什么它们默认一页只显示 40~60 件商品，还提供大量筛选条件？如果一次性把全部几百万件商品返回给你，会发生什么？"
预期价值目标 让学生理解：技术不是冰冷的代码，每一个分页参数、每一个查询条件都是为了让用户用得舒服；后端工程师的价值在于"用技术解决用户真实痛点"

思政自然融入，不空喊口号。通过真实场景让学生体会"用户体验"背后的工程思考。

七、课堂练习或随堂测验

随堂练习（5 分钟，讲解结束前进行）

判断题（口头快速作答）：

  1. <where> 标签会自动去除首个 AND/OR 关键字。（✓）
  2. LambdaQueryWrapper 用字符串字段名构造条件。（✗，用方法引用）
  3. MyBatis-Plus 分页插件无需配置即可直接使用 selectPage。（✗，需配置 MybatisPlusInterceptor）
  4. Page 对象的 current 表示当前页码，size 表示每页条数。（✓）

详细题目与解析见 题库.md。此处仅作课堂快速互动，不计分。

八、课后任务

  1. 阅读：通读同文件夹 教学资料.md，重点掌握 <if>/<where>/<foreach> 标签、QueryWrapper/LambdaQueryWrapper 方法、分页插件配置与 Page 对象。
  2. 动手实践：
    • 在 CTTS 项目中配置 MybatisPlusInterceptor 分页插件。
    • 实现 GET /api/tasks/page 分页接口，支持 projectId、status、title（模糊）三个可选条件。
    • 用 Apifox 测试不同参数组合（仅 projectId、仅 title、三者皆有、空参数），验证返回结构。
  3. 思考：对比 XML 动态 SQL 与 LambdaQueryWrapper 两种实现方式，各列出 3 个优点与 3 个缺点，下次课抽查。
  4. 常见报错排查：自行制造以下错误并观察报错信息，记录原因与解决办法：
    • 不配置分页插件直接调 selectPage（无分页效果）。
    • LambdaQueryWrapper 方法引用写错字段名。
    • XML 中 <foreach> 的 collection 属性写错。
  5. 拓展阅读：了解 MyBatis-Plus PaginationInnerInterceptor 的 overflow、maxLimit 等高级配置项（选做）。
