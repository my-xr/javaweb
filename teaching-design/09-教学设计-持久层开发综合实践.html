二、教学目标

知识目标

  1. 综合理解持久层开发的完整链路：建表 → 实体 → Mapper 接口 → XML/注解 SQL → 测试验证。
  2. 巩固 MyBatis-Plus 的核心注解：@TableName、@TableId、@TableField 的使用场景与写法。
  3. 巩固 BaseMapper 提供的通用 CRUD 与自定义查询方法的协作方式。
  4. 巩固动态 SQL 标签 <if>、<where>、<foreach> 在多条件查询中的应用。
  5. 巩固条件构造器 QueryWrapper / LambdaQueryWrapper 与 XML 动态 SQL 的选型思路。
  6. 巩固分页查询 Page + selectPage 的标准写法与分页插件配置。
  7. 理解多表关联查询（JOIN）与 resultMap 嵌套映射的搭配使用方式。

能力目标

  1. 能够依据表结构独立设计实体类，正确使用 MyBatis-Plus 注解完成 ORM 映射。
  2. 能够为三张表（task / task_submission / task_review）独立编写 Mapper 接口，合理拆分通用方法与自定义方法。
  3. 能够编写 XML 映射文件实现动态条件查询、分页查询、多表 JOIN 查询，并正确配置 resultMap 嵌套映射。
  4. 能够编写 JUnit 测试类对每个 Mapper 方法进行验证，使用断言而非 System.out.println 验证结果。
  5. 能够定位并排查持久层开发中的常见问题（字段映射、参数绑定、N+1 查询、分页失效等）。

素质目标（课程思政）

  1. 工匠精神：SQL 写得好不好直接影响系统性能，每一行 SQL、每一个索引、每一次关联都要认真对待，培养"对每行代码负责"的工程素养。
  2. 工程思维：从单表 CRUD 到多表关联，培养从局部到整体的系统化建模能力。
  3. 质量意识：用测试驱动开发，写一行测一行，建立"代码即文档、测试即证据"的质量意识。

业务背景

CTTS 业务流：教师发布任务 → 学生提交成果 → 教师评审打分

              task 表      task_submission 表   task_review 表

三张表通过外键关联：

  • task.project_id → training_project.id
  • task_submission.task_id → task.id
  • task_submission.student_id → sys_user.id
  • task_review.submission_id → task_submission.id
  • task_review.reviewer_id → sys_user.id

六、课程思政融入点

项目 内容
融入点 工匠精神——SQL 写得好不好直接影响系统性能，每一行 SQL 都要认真对待
技术关联 一条低效 SQL 可能让整个系统卡顿（如 SELECT *、N+1 查询、缺索引的 JOIN）；动态 SQL 拼错可能引发 SQL 注入；resultMap 映射错可能导致数据丢失
引导问题 "同样是查询某个学生所有提交，写一条 JOIN 快，还是写两条单表查询再在 Java 里拼快？为什么？N+1 问题是怎么产生的？"
预期价值目标 树立"对每行 SQL 负责"的工程素养；建立"性能无小事、细节决定成败"的工匠精神；激发对国产 ORM 框架 MyBatis-Plus 的认同感

思政自然融入，不空喊口号。通过真实 SQL 性能案例让学生体会"为什么每行 SQL 都要认真对待"。

七、课堂练习或随堂测验

随堂练习（5 分钟，讲解结束前进行）

代码纠错题（口头快速作答）：以下 XML 动态 SQL 有几处问题？

<select id="selectByCondition" resultType="Task">
    SELECT * FROM task
    WHERE
    <if test="projectId != null">
        project_id = #{projectId}
    </if>
    <if test="status != null">
        AND status = #{status}
    </if>
</select>

参考答案：① 缺少 <where> 标签，当 projectId 为 null 时 SQL 会变成 WHERE AND status = ? 语法错误；② resultType="Task" 应使用全限定类名或配合 resultMap；③ 没有处理空字符串情况（建议 status != null and status != ''）。

详细题目与解析见 题库.md。此处仅作课堂快速互动，不计分。
