二、教学目标

2.1 知识目标

  • K1：能够复述用户注册登录的完整流程（注册：用户名唯一性校验→密码加密→入库；登录：查询用户→校验密码→生成凭证→返回；登出）。
  • K2：理解明文存储密码的危害，能够对比 MD5 与 BCrypt 加密算法的优劣，说明加盐（salt）的作用。
  • K3：能够阐述 Session 认证的工作机制（服务器存储 Session、Cookie 传递 SessionID）。
  • K4：能够阐述 Token 认证的工作机制（登录返回 Token、客户端存储、Header 携带、服务端解析）。
  • K5：能够从存储位置、扩展性、跨域、前后端分离适配性四个维度对比 Session 与 Token，并能说明前后端分离架构选择 Token 的原因。

2.2 能力目标

  • A1：能够独立配置 BCryptPasswordEncoder 到 Spring 容器中。
  • A2：能够使用 @Valid 配合 DTO 完成注册参数校验。
  • A3：能够独立实现注册接口（用户名唯一性校验 + BCrypt 加密 + 入库）。
  • A4：能够独立实现登录接口（查询用户 + BCrypt 校验 + 生成简单 Token 返回）。
  • A5：能够使用 Apifox/Postman 完成接口测试，并能够定位常见报错（如 405、500、用户名重复、密码不匹配等）。

2.3 素质目标（课程思政）

  • S1：树立数据安全与用户隐私保护意识——密码加密是开发者的法律底线和职业底线（《个人信息保护法》《数据安全法》）。
  • S2：培养工程严谨态度——任何一行涉及安全的代码都需经得起审计。
  • S3：建立技术选型的辩证思维——没有最好的方案，只有最合适的方案（Session 与 Token 的取舍）。

三、教学重点

  1. 用户注册登录的完整业务流程。
  2. BCrypt 加密算法的原理与 BCryptPasswordEncoder 的使用。
  3. Session 认证与 Token 认证的核心机制对比。
  4. 前后端分离架构下 Token 认证成为主流的原因。

四、教学难点

  1. 为什么 MD5 不安全、BCrypt 安全：理解彩虹表攻击、加盐的意义以及 BCrypt 自带盐、慢哈希的设计。
  2. BCryptPasswordEncoder 的匹配机制：同一个明文每次加密结果不同，却能正确校验（盐嵌入在哈希结果中）。
  3. Session 与 Token 的本质区别：状态存储位置不同导致扩展性、跨域、CSRF 等一系列差异。

五、学情分析

  • 前置基础：学生已学习 Spring Boot IoC/DI、RESTful 接口设计、MyBatis-Plus CRUD、统一响应体、全局异常处理、@Valid 参数校验等知识，具备独立编写 CRUD 接口的能力。
  • 薄弱环节：对"安全"概念停留在感性认识，多数同学听说过 MD5，但不理解为什么不安全；对 Session/Token 仅停留在"用过的"层面，未深入思考原理。
  • 学习诉求：临近实习面试，学生希望掌握"面试题级别"的深度知识，对"密码为什么不能明文存储"等高频面试题兴趣浓厚。
  • 班级差异：约 30% 学生基础扎实，可加速；约 20% 学生对 Spring Security 较陌生，需要在配置类环节多花时间演示。

七、教学准备

  • 教师准备：CTTS 项目骨架代码（已含 sys_user 表、User 实体、UserMapper）、Apifox 测试集合、密码泄漏案例素材（如 CSDN 600万账号泄漏事件）。
  • 学生准备：复习 MyBatis-Plus CRUD、@Valid 校验、统一响应体；预读 Spring Security PasswordEncoder 文档。
  • 环境准备：JDK 17、IDEA 2023.x、MySQL 8.x、Postman/Apifox、Git。

九、课后作业

  1. 项目任务（必做）：在 CTTS 项目中实现用户注册与登录接口，要求：
    • 注册接口 /api/auth/register：用户名唯一性校验 + @Valid 参数校验 + BCrypt 加密 + 入库。
    • 登录接口 /api/auth/login：根据用户名查询 + BCrypt 校验密码 + 生成简单 Token（UUID 即可）返回。
    • 提交代码到 Git，附带 Apifox 测试截图。
  2. 思考题（必做）：为什么 BCrypt 每次加密同一明文结果都不同，却能正确校验密码？
  3. 拓展任务（选做）：尝试将简单 Token 替换为 JWT（Json Web Token），对比两者的差异。
  4. 面试题准备：背诵并理解"密码为什么不能明文存储""Session 与 Token 区别"两个高频面试题。
