06-单选-01 ★

题目：JDBC 是 Java 平台提供的一套什么 API？

  • A
    Web 服务调用标准
  • B
    数据库访问标准
  • C
    文件 IO 标准
  • D
    网络通信标准

答案：B 解析：JDBC（Java Database Connectivity）是 Java 平台提供的数据库访问标准 API，位于 java.sql 与 javax.sql 包下，为 Java 开发者提供统一数据库访问方式。

06-单选-02 ★

题目：MySQL 8.x 的 JDBC 驱动类全限定名是？

  • A
    com.mysql.jdbc.Driver
  • B
    com.mysql.cj.jdbc.Driver
  • C
    org.mysql.Driver
  • D
    mysql.jdbc.Driver

答案：B 解析：MySQL 8.x 驱动类为 com.mysql.cj.jdbc.Driver（带 cj）。com.mysql.jdbc.Driver 是 MySQL 5.x 旧类名，已废弃。

06-单选-03 ★

题目：JDBC 操作数据库的核心六步流程，正确顺序是？

  • A
    加载驱动 → 创建 Statement → 获取连接 → 执行 SQL → 处理结果集 → 关闭资源
  • B
    获取连接 → 加载驱动 → 创建 Statement → 执行 SQL → 处理结果集 → 关闭资源
  • C
    加载驱动 → 获取连接 → 创建 Statement → 执行 SQL → 处理结果集 → 关闭资源
  • D
    创建 Statement → 加载驱动 → 获取连接 → 执行 SQL → 处理结果集 → 关闭资源

答案：C 解析：正确顺序为加载驱动 → 获取连接 → 创建 Statement → 执行 SQL → 处理结果集 → 关闭资源。每一步依赖前一步产物。

06-单选-04 ★

题目：在 JDBC 中，加载 MySQL 驱动的代码是？

  • A
    DriverManager.load("com.mysql.cj.jdbc.Driver")
  • B
    Class.forName("com.mysql.cj.jdbc.Driver")
  • C
    Class.load("com.mysql.cj.jdbc.Driver")
  • D
    DriverManager.forName("com.mysql.cj.jdbc.Driver")

答案：B 解析：使用 Class.forName(类全限定名) 加载驱动类到 JVM。JDBC 4.0+ 可省略此行（SPI 自动加载），但教学场景建议保留。

06-单选-05 ★

题目：获取数据库连接的方法是？

  • A
    Connection.getConnection(url, user, password)
  • B
    DriverManager.connect(url, user, password)
  • C
    DriverManager.getConnection(url, user, password)
  • D
    DataSource.openConnection()

答案：C 解析：原生 JDBC 使用 DriverManager.getConnection(url, user, password) 获取连接，返回 Connection 对象。

06-单选-06 ★

题目：执行 SELECT 查询语句应使用哪个方法？

  • A
    executeUpdate()
  • B
    executeQuery()
  • C
    executeSelect()
  • D
    executeInsert()

答案：B 解析：executeQuery() 执行 SELECT 返回 ResultSet；executeUpdate() 执行 INSERT/UPDATE/DELETE 返回受影响行数 int。

06-单选-07 ★

题目：执行 INSERT/UPDATE/DELETE 语句应使用哪个方法？

  • A
    executeQuery()
  • B
    executeUpdate()
  • C
    executeInsert()
  • D
    executeDelete()

答案：B 解析：executeUpdate() 用于执行 DML 语句（INSERT/UPDATE/DELETE），返回受影响行数；DDL（CREATE/DROP）也可使用此方法。

06-单选-08 ★

题目：PreparedStatement 设置 String 类型参数的方法是？

  • A
    pstmt.setString(0, value)
  • B
    pstmt.setString(1, value)
  • C
    pstmt.setString("column", value)
  • D
    pstmt.addString(1, value)

答案：B 解析：PreparedStatement 参数下标从 1 开始（不是 0）。语法为 setString(index, value)，index 是 SQL 中 ? 的位置。

06-单选-09 ★

题目：ResultSet 中移动游标到下一行的方法是？

  • A
    rs.next()
  • B
    rs.hasNext()
  • C
    rs.move()
  • D
    rs.forward()

答案：A 解析：rs.next() 将游标向下移动一行，返回 boolean 表示是否有数据。初始游标在第一行之前，必须先调用 next() 才能读取数据。

06-单选-10 ★

题目：JDBC 推荐使用的资源关闭方式是？

  • A
    手动在 try 块中调用 close()
  • B
    不需要关闭，JVM 会自动回收
  • C
    在 finally 块中按 rs → pstmt → conn 顺序关闭
  • D
    使用 try-with-resources 自动关闭

答案：D 解析：Java 7+ 推荐使用 try-with-resources 语句，实现 AutoCloseable 的资源会自动调用 close()。无需手动写 finally。

06-单选-11 ★

题目：JDBC 的四大痛点不包括以下哪一项？

  • A
    代码繁琐
  • B
    资源易泄漏
  • C
    不支持事务
  • D
    SQL 硬编码

答案：C 解析：JDBC 四大痛点是：代码繁琐、资源易泄漏、SQL 硬编码、结果集手动映射。JDBC 支持事务（conn.setAutoCommit(false)），所以 C 不属于痛点。

06-单选-12 ★

题目：MyBatis 属于以下哪种类型的框架？

  • A
    全自动 ORM
  • B
    半自动 ORM
  • C
    不是 ORM 框架
  • D
    数据库连接池

答案：B 解析：MyBatis 是半自动 ORM，开发者手写 SQL，框架负责参数绑定与结果映射。JPA/Hibernate 是全自动 ORM。

06-单选-13 ★

题目：MyBatis-Plus 与 MyBatis 的关系是？

  • A
    MyBatis-Plus 替代了 MyBatis
  • B
    MyBatis-Plus 是 MyBatis 的增强工具
  • C
    两者无任何关系
  • D
    MyBatis 是 MyBatis-Plus 的增强

答案：B 解析：MyBatis-Plus 是 MyBatis 的增强工具（"只做增强不做改变"），底层仍是 MyBatis，可混用原生功能。

06-单选-14 ★

题目：Spring Boot 3 项目集成 MyBatis-Plus 应使用哪个 starter？

  • A
    mybatis-plus-boot-starter
  • B
    mybatis-plus-spring-boot3-starter
  • C
    mybatis-spring-boot-starter
  • D
    spring-boot-starter-mybatis

答案：B 解析：Spring Boot 3.x 必须使用 mybatis-plus-spring-boot3-starter（带 boot3）。Spring Boot 2.x 用 mybatis-plus-boot-starter。

06-单选-15 ★

题目：MySQL 8 的官方 JDBC 驱动 Maven 坐标 artifactId 是？

  • A
    mysql-connector-java
  • B
    mysql-connector-j
  • C
    mysql-jdbc
  • D
    mysql-driver

答案：B 解析：MySQL 8.0.31 后驱动包名从 mysql-connector-java 改为 mysql-connector-j，groupId 从 mysql 改为 com.mysql。

06-单选-16 ★

题目：JDBC URL 中 serverTimezone=Asia/Shanghai 参数的作用是？

  • A
    设置客户端时区
  • B
    设置服务器时区
  • C
    设置连接超时
  • D
    设置字符编码

答案：B 解析：serverTimezone 指定服务器时区，MySQL 8 必填，否则报"The server time zone value is unrecognized"。

06-单选-17 ★★

题目：以下 JDBC URL 配置正确的是？

  • A
    jdbc:mysql://localhost:3306/ctts
  • B
    jdbc:mysql://localhost:3306/ctts?serverTimezone=Asia/Shanghai
  • C
    jdbc:mysql://localhost/ctts?serverTimezone=Asia/Shanghai
  • D
    jdbc:mysql://localhost:3306:ctts?serverTimezone=Asia/Shanghai

答案：B 解析：JDBC URL 格式为 jdbc:mysql://host:port/database?params。A 缺时区参数，C 缺端口，D 端口与数据库之间用了冒号（应为斜杠）。

06-单选-18 ★★

题目：关于 Statement 和 PreparedStatement，下列说法正确的是？

  • A
    Statement 性能更好
  • B
    PreparedStatement 不能防止 SQL 注入
  • C
    Statement 适用于带参数的动态 SQL
  • D
    PreparedStatement 支持参数预编译，可防止 SQL 注入

答案：D 解析：PreparedStatement 预编译 SQL，参数用 ? 占位后通过 setXxx 绑定，能防止 SQL 注入；Statement 拼接 SQL 字符串易被注入。生产环境推荐 PreparedStatement。

06-单选-19 ★★

题目：try-with-resources 中声明多个资源的关闭顺序是？

  • A
    按声明顺序关闭
  • B
    按声明逆序关闭
  • C
    随机顺序关闭
  • D
    同时关闭

答案：B 解析：try-with-resources 按声明逆序关闭资源（后声明先关闭）。如声明顺序为 Connection、PreparedStatement、ResultSet，则关闭顺序为 ResultSet → PreparedStatement → Connection。

06-单选-20 ★★

题目：MyBatis-Plus 的 BaseMapper 接口不直接提供以下哪个方法？

  • A
    insert(entity)
  • B
    updateById(entity)
  • C
    deleteById(id)
  • D
    joinSelect(wrapper)

答案：D 解析：BaseMapper 提供 insert、updateById、deleteById、selectById、selectList 等通用方法，不提供 joinSelect（多表连接需自定义 SQL）。

06-单选-21 ★★

题目：MyBatis-Plus 实体类 User 对应数据库表 sys_user，应使用哪个注解声明表名？

  • A
    @Table("sys_user")
  • B
    @TableName("sys_user")
  • C
    @Entity("sys_user")
  • D
    @Table(name = "sys_user")

答案：B 解析：MyBatis-Plus 使用 @TableName("表名") 注解声明实体类对应的表名。若类名与表名一致（如 User 对应 user 表）可省略。

06-单选-22 ★★

题目：Spring Boot 集成 MyBatis-Plus 后，默认使用的数据库连接池是？

  • A
    DBCP
  • B
    Druid
  • C
    HikariCP
  • D
    C3P0

06-单选-23 ★★

题目：MyBatis-Plus 实体类字段 createTime 自动映射数据库列 create_time，依赖的配置是？

  • A
    mybatis-plus.configuration.map-underscore-to-camel-case=true
  • B
    mybatis-plus.global-config.db-config.underscore=true
  • C
    mybatis-plus.configuration.camel-case=true
  • D
    无需配置，自动映射

答案：A 解析：MyBatis-Plus 默认开启下划线转驼峰（map-underscore-to-camel-case=true），createTime 自动映射 create_time。若手动关闭则映射失败。

06-单选-24 ★★

题目：以下哪种情况会导致 Access denied for user 'root'@'localhost' 报错？

06-单选-25 ★★

题目：以下哪种情况会导致 ClassNotFoundException: com.mysql.cj.jdbc.Driver 报错？

06-单选-26 ★★

06-单选-27 ★★

题目：MyBatis-Plus 的核心优势不包括以下哪一项？

06-单选-28 ★★

06-单选-29 ★★

06-单选-30 ★★★

题目：以下关于 JDBC 4.0+ 自动加载驱动机制的说法，正确的是？

  • A
    必须显式调用 Class.forName() 加载驱动
  • B
    通过 SPI 机制自动加载，Class.forName() 可省略
  • C
    通过 DriverManager.registerDriver() 注册驱动
  • D
    通过 Spring Boot 自动配置驱动

答案：B 解析：JDBC 4.0+ 引入 SPI 机制，驱动 jar 的 META-INF/services/java.sql.Driver 声明驱动类全限定名，DriverManager 类加载时自动发现并加载。因此 Class.forName() 可省略，但教学场景建议保留。

06-多选-01 ★

题目：以下哪些是 JDBC 操作数据库的核心步骤？（多选）

  • A
    加载驱动 Class.forName
  • B
    获取连接 DriverManager.getConnection
  • C
    创建 PreparedStatement
  • D
    执行 SQL executeQuery / executeUpdate
  • E
    处理 ResultSet
  • F
    关闭资源

答案：ABCDEF 解析：六步全部是 JDBC 核心步骤，缺一不可。

06-多选-02 ★

题目：JDBC 的四大痛点包括哪些？（多选）

  • A
    代码繁琐（六步流程）
  • B
    资源易泄漏
  • C
    SQL 硬编码在 Java 文件中
  • D
    结果集手动映射到对象
  • E
    不支持事务
  • F
    不支持连接池

答案：ABCD 解析：JDBC 四大痛点是 ABCD。JDBC 本身支持事务（setAutoCommit），也支持配合第三方连接池使用，所以 EF 不属于痛点。

06-多选-03 ★

题目：以下哪些是 MyBatis-Plus 相对 MyBatis 的增强功能？（多选）

  • A
    内置 BaseMapper 提供 CRUD 方法
  • B
    条件构造器 QueryWrapper
  • C
    分页插件 PaginationInnerInterceptor
  • D
    代码生成器
  • E
    替代了 MyBatis 所有原生功能
  • F
    SQL 与 Java 代码分离

答案：ABCD 解析：ABCD 都是 MyBatis-Plus 的增强功能。E 错误（MP 不替代 MyBatis，是增强）。F 是 MyBatis 本身就具备的特性，不是 MP 增强的。

06-多选-04 ★

题目：Spring Boot 3 项目集成 MyBatis-Plus 需要引入哪些依赖？（多选）

  • A
    mybatis-plus-spring-boot3-starter
  • B
    mysql-connector-j
  • C
    mybatis-spring-boot-starter
  • D
    spring-boot-starter-web
  • E
    mybatis-plus-boot-starter

答案：AB 解析：A 是 Spring Boot 3 专用 MyBatis-Plus starter，B 是 MySQL 驱动。C 是 MyBatis 原生 starter（非 MP），D 是 Web 依赖（非数据库必需）。E 是 Spring Boot 2.x 用法，3.x 应使用 A。

06-多选-05 ★★

题目：以下哪些是 JDBC URL 中常见的必要参数？（多选）

  • A
    serverTimezone=Asia/Shanghai
  • B
    useSSL=false
  • C

06-论述-01 ★★

题目：请详细描述 JDBC 操作数据库的六步流程，并说明每一步的作用。

评分标准（10分）：

  • 六步流程完整正确（6分，每步1分）
  • 每步作用说明准确（4分）

参考答案：

JDBC 操作数据库的六步流程如下：

  1. 加载驱动：Class.forName("com.mysql.cj.jdbc.Driver")，将 MySQL 驱动类加载到 JVM，注册到 DriverManager。JDBC 4.0+ 可省略（SPI 自动加载）。

  2. 获取连接：DriverManager.getConnection(url, user, password)，建立与数据库的 TCP 连接，返回 Connection 对象。Connection 是后续所有操作的基础。

  3. 创建 Statement：conn.prepareStatement(sql)，创建预编译 SQL 执行对象 PreparedStatement。推荐使用 PreparedStatement 而非 Statement，可防止 SQL 注入。

  4. 执行 SQL：

    • 查询用 executeQuery() 返回 ResultSet
    • 增删改用 executeUpdate() 返回受影响行数 int

  5. 处理结果集：while(rs.next()) 移动游标遍历每行，使用 rs.getString("列名")、rs.getLong("列名") 等方法取值，并手动映射到 Java 对象。

  6. 关闭资源：使用 try-with-resources 自动关闭，关闭顺序为 ResultSet → PreparedStatement → Connection（先开后关）。不关闭会导致资源泄漏，最终耗尽数据库连接。

06-论述-02 ★★

题目：JDBC 原生开发有哪些痛点？MyBatis 与 MyBatis-Plus 分别解决了哪些问题？

评分标准（10分）：

  • JDBC 四大痛点准确（4分，每点1分）
  • MyBatis 解决方案说明（3分）
  • MyBatis-Plus 增强说明（3分）

参考答案：

JDBC 四大痛点：

  1. 代码繁琐：每次操作都要走六步流程，简单的查询也要 30+ 行代码。
  2. 资源易泄漏：忘记 close、异常导致 close 未执行，最终耗尽连接池。
  3. SQL 硬编码：SQL 字符串写在 Java 文件中，修改需重新编译，可维护性差。
  4. 结果集手动映射：rs.getString("name") → user.setName()，字段多了代码冗长易错。

MyBatis 的解决：

  • SQL 与 Java 代码分离（写在 XML 或注解中），解决 SQL 硬编码。
  • 框架托管资源管理（SqlSession 内部关闭 Connection 等），解决资源泄漏。
  • 自动结果映射（resultType + 驼峰转换），解决手动映射。
  • 仍需手写 SQL，未解决代码繁琐（简单 CRUD 仍要写）。

MyBatis-Plus 的增强：

  • 内置 BaseMapper 提供 20+ 通用 CRUD 方法，简单 CRUD 零 SQL，解决代码繁琐。
  • QueryWrapper 链式条件构造器，避免 SQL 拼接。
  • 分页插件，自动分页。
  • 代码生成器，自动生成 Entity/Mapper/Service 骨架。
  • 完全兼容 MyBatis 原生功能，复杂查询仍可手写 SQL。

题目：在 CTTS 项目中集成 MyBatis-Plus 的完整步骤是什么？请从依赖添加到连接验证逐步说明，并列举至少 3 种常见报错及排查方法。

  • 常见报错列举至少 3 种（3分）

集成步骤：

  1. 确认 MySQL 已安装启动：net start mysql80，mysql -u root -p 验证登录。

  2. 创建数据库与表：

    CREATE DATABASE ctts DEFAULT CHARACTER SET utf8mb4;
USE ctts;
CREATE TABLE sys_user(id BIGINT PRIMARY KEY AUTO_INCREMENT, ...);
INSERT INTO sys_user ...;

  3. 添加 Maven 依赖（pom.xml）：

    • mybatis-plus-spring-boot3-starter（Spring Boot 3 专用）
    • mysql-connector-j（MySQL 8 驱动）
    • lombok、spring-boot-starter-test 等辅助依赖

  4. 配置数据源（application.yml）：

    spring:
  datasource:
    url: jdbc:mysql://localhost:3306/ctts?serverTimezone=Asia/Shanghai&useSSL=false&characterEncoding=utf8&allowPublicKeyRetrieval=true
    username: root
    password: 123456
    driver-class-name: com.mysql.cj.jdbc.Driver

常见报错及排查：

  1. 时区错误：The server time zone value 'xxx' is unrecognized。排查：检查 URL 是否有 serverTimezone=Asia/Shanghai。

  2. 驱动类找不到：ClassNotFoundException: com.mysql.cj.jdbc.Driver。排查：检查 pom.xml 是否引入 mysql-connector-j，注意 MySQL 8 用新名而非 mysql-connector-java。

  3. 密码错误：Access denied for user 'root'@'localhost'。排查：先用 mysql -u root -p 验证密码，对比 application.yml 中的 password 是否一致。

  4. 数据库不存在：Unknown database 'ctts'。排查：执行 SHOW DATABASES; 确认 ctts 已创建。

  5. Public Key Retrieval 错误：Public Key Retrieval is not allowed。排查：URL 添加 allowPublicKeyRetrieval=true。

  6. 连接超时：Communications link failure。排查：检查 MySQL 服务是否启动，端口 3306 是否被防火墙拦截。

题目：对比 JDBC、MyBatis、MyBatis-Plus、JPA(Hibernate) 四种数据库访问方案，说明各自的特点与适用场景，并说明 CTTS 项目为什么选择 MyBatis-Plus。

参考答案：

四种方案对比：

方案 类型 SQL 编写 特点 适用场景
JDBC 底层 API 手写 + 手动处理结果集 繁琐易错，但最灵活 学习理解、底层框架开发
MyBatis 半自动 ORM 手写 SQL，框架映射结果 SQL 灵活可控，国内主流 复杂业务 SQL、报表系统
MyBatis-Plus MyBatis 增强 简单 CRUD 内置，复杂 SQL 手写 兼顾开发效率与 SQL 灵活度 中大型业务系统（互联网主流）
JPA/Hibernate 全自动 ORM 框架自动生成 开发快，但 SQL 不可控 简单 CRUD、对象关系映射重的系统

适用场景分析：

  • JDBC：仅用于理解原理或框架开发场景，业务代码不直接使用。
  • MyBatis：业务复杂、SQL 灵活度要求高，如电商订单查询、报表统计。
  • MyBatis-Plus：业务系统 80% 简单 CRUD + 20% 复杂查询，兼顾效率与灵活度。
  • JPA：对象关系映射复杂、CRUD 为主，如内容管理系统、配置管理。

CTTS 选择 MyBatis-Plus 的理由：

  1. 业务场景匹配：CTTS 是中大型业务系统，包含 5 张核心表（用户/项目/任务/提交/评审），80% 操作是简单 CRUD，MyBatis-Plus 内置方法可零 SQL 完成。
  2. 复杂查询支持：CTTS 后续涉及多表关联查询（任务-提交-评审），MyBatis-Plus 兼容 MyBatis 原生 XML SQL，可手写复杂 SQL。

题目：使用原生 JDBC 编写一个 UserJdbcDao 类，实现以下功能（查询 CTTS 项目的 sys_user 表）：

要求：

  • 使用 try-with-resources 自动关闭资源
  • 实体类字段：id、username、password、name、role、phone、createTime
  • 数据库连接信息：URL=jdbc:mysql://localhost:3306/ctts?serverTimezone=Asia/Shanghai，user=root，password=123456

评分标准（15分）：

  • 类结构与常量定义正确（2分）
  • 5 个方法各 2.5 分（共 12.5 分）：
    • 方法签名与返回类型正确（0.5分）
    • 使用 PreparedStatement（0.5分）
    • 使用 try-with-resources（0.5分）
    • SQL 正确（0.5分）
    • 结果映射/参数设置正确（0.5分）
  • 代码风格规范（0.5分）

参考答案：

package com.ctts.dao;

import com.ctts.entity.User;

import java.sql.*;
import java.util.ArrayList;
import java.util.List;

public class UserJdbcDao {

    private static final String URL =
            "jdbc:mysql://localhost:3306/ctts?serverTimezone=Asia/Shanghai&characterEncoding=utf8";
    private static final String USER = "root";
    private static final String PASSWORD = "123456";
    private static final String DRIVER = "com.mysql.cj.jdbc.Driver";

    static {
        try {
            Class.forName(DRIVER);
        } catch (ClassNotFoundException e) {
            throw new RuntimeException("MySQL 驱动加载失败", e);
        }
    }

    /** 根据ID查询用户 */
    public User findById(Long id) {
        String sql = "SELECT id, username, password, name, role, phone, create_time " +
                     "FROM sys_user WHERE id = ?";
        try (Connection conn = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement pstmt = conn.prepareStatement(sql)) {
            pstmt.setLong(1, id);
            try (ResultSet rs = pstmt.executeQuery()) {
                if (rs.next()) {
                    return mapRow(rs);
                }
            }
        } catch (SQLException e) {
            e.printStackTrace();
        }
        return null;
    }

    /** 根据用户名查询用户 */
    public User findByUsername(String username) {
        String sql = "SELECT id, username, password, name, role, phone, create_time " +
                     "FROM sys_user WHERE username = ?";
        try (Connection conn = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement pstmt = conn.prepareStatement(sql)) {
            pstmt.setString(1, username);
            try (ResultSet rs = pstmt.executeQuery()) {
                if (rs.next()) {
                    return mapRow(rs);
                }
            }
        } catch (SQLException e) {
            e.printStackTrace();
        }
        return null;
    }

    /** 查询所有用户 */
    public List<User> findAll() {
        String sql = "SELECT id, username, password, name, role, phone, create_time FROM sys_user";
        List<User> list = new ArrayList<>();
        try (Connection conn = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement pstmt = conn.prepareStatement(sql);
             ResultSet rs = pstmt.executeQuery()) {
            while (rs.next()) {
                list.add(mapRow(rs));
            }
        } catch (SQLException e) {
            e.printStackTrace();
        }
        return list;
    }

    /** 新增用户 */
    public int insert(User user) {
        String sql = "INSERT INTO sys_user(username, password, name, role, phone, create_time) " +
                     "VALUES(?, ?, ?, ?, ?, NOW())";
        try (Connection conn = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement pstmt = conn.prepareStatement(sql)) {
            pstmt.setString(1, user.getUsername());
            pstmt.setString(2, user.getPassword());
            pstmt.setString(3, user.getName());
            pstmt.setString(4, user.getRole());
            pstmt.setString(5, user.getPhone());
            return pstmt.executeUpdate();
        } catch (SQLException e) {
            e.printStackTrace();
            return 0;
        }
    }

    /** 根据ID删除用户 */
    public int deleteById(Long id) {
        String sql = "DELETE FROM sys_user WHERE id = ?";
        try (Connection conn = DriverManager.getConnection(URL, USER, PASSWORD);
             PreparedStatement pstmt = conn.prepareStatement(sql)) {
            pstmt.setLong(1, id);
            return pstmt.executeUpdate();
        } catch (SQLException e) {
            e.printStackTrace();
            return 0;
        }
    }

    /** 私有方法：将 ResultSet 行映射为 User 对象 */
    private User mapRow(ResultSet rs) throws SQLException {
        User user = new User();
        user.setId(rs.getLong("id"));
        user.setUsername(rs.getString("username"));
        user.setPassword(rs.getString("password"));
        user.setName(rs.getString("name"));
        user.setRole(rs.getString("role"));
        user.setPhone(rs.getString("phone"));
        user.setCreateTime(rs.getTimestamp("create_time"));
        return user;
    }
}

解析：

  • 使用静态代码块加载驱动，避免每次方法都加载。
  • 每个方法独立获取连接（生产环境应使用连接池），try-with-resources 自动关闭。
  • mapRow 私有方法封装 ResultSet → User 映射，避免代码重复。
  • INSERT 使用 NOW() 函数设置 create_time，避免 Java 端时区问题。

package com.ctts;

import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;

import javax.sql.DataSource;
import java.sql.Connection;
import java.sql.DatabaseMetaData;
import java.sql.SQLException;

import static org.junit.jupiter.api.Assertions.*;

/**
 * 数据库连接验证测试类
 * 验证 CTTS 项目 MyBatis-Plus 集成后能成功连接 MySQL 数据库
 */
@SpringBootTest
public class DataSourceConnectionTest {

    @Autowired
    private DataSource dataSource;  // Spring Boot 自动注入 HikariDataSource

    @Test
    public void testConnection() throws SQLException {
        // 1. 打印 DataSource 类型
        System.out.println("========== 数据源类型 ==========");
        System.out.println("DataSource = " + dataSource.getClass().getName());

        // 2. 获取 Connection 并验证（使用 try-with-resources）
        try (Connection conn = dataSource.getConnection()) {
            System.out.println("========== 连接成功 ==========");
            System.out.println("Connection = " + conn);
            System.out.println("是否已关闭 = " + conn.isClosed());
            System.out.println("是否有效 = " + conn.isValid(3));

            // 3. 打印数据库元数据
            DatabaseMetaData metaData = conn.getMetaData();
            System.out.println("========== 数据库元数据 ==========");
            System.out.println("数据库产品名 = " + metaData.getDatabaseProductName());
            System.out.println("数据库版本 = " + metaData.getDatabaseProductVersion());
            System.out.println("驱动名 = " + metaData.getDriverName());
            System.out.println("驱动版本 = " + metaData.getDriverVersion());
            System.out.println("URL = " + metaData.getURL());
            System.out.println("用户名 = " + metaData.getUserName());

            // 4. JUnit 5 断言验证
            assertNotNull(conn, "Connection 不应为 null");
            assertFalse(conn.isClosed(), "连接不应处于关闭状态");
            assertTrue(conn.isValid(3), "连接应在3秒内有效");
        }

        System.out.println("========== 测试通过：数据库连接正常 ==========");
    }
}
