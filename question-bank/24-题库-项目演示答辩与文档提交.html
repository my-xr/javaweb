24-单选-01 ★ M1 Java Web基础

HTTP协议中，用于向服务器提交数据并创建资源的请求方法是（ ）。

  • A
    GET
  • B
    POST
  • C
    PUT
  • D
    DELETE
答案与解析

答案：B

解析：POST方法用于向服务器提交数据并创建新资源；GET用于查询；PUT用于更新/替换资源；DELETE用于删除。RESTful风格中POST对应"新增"语义。

24-单选-02 ★ M1 Java Web基础

Servlet生命周期中，仅执行一次的方法是（ ）。

  • A
    service()
  • B
    doGet()
  • C
    init()
  • D
    destroy()
答案与解析

答案：C

解析：init()在Servlet实例化后仅执行一次，完成初始化；service()每次请求都执行；doGet()处理GET请求；destroy()在卸载时执行一次。但题目强调"初始化"的一次性，故选init()。destroy()虽也一次但属销毁阶段。

24-单选-05 ★★ M2 SpringBoot

关于SpringBoot自动配置，下列说法正确的是（ ）。

  • A
    自动配置通过@Bean在application.yml中定义
  • B
    自动配置类位于spring-boot-autoconfigurejar中，通过@Conditional条件装配
  • C
    自动配置意味着所有Bean都被默认加载
  • D
    @SpringBootApplication只包含@ComponentScan
答案与解析

答案：B

解析：自动配置类通过@ConditionalOnClass/@ConditionalOnMissingBean等条件注解按需装配，避免全量加载。@SpringBootApplication是@SpringBootConfiguration+@EnableAutoConfiguration+@ComponentScan的组合。

24-单选-06 ★ M2 SpringBoot

  • A
    @Value
  • B
    @Autowired
  • C
    @Bean
  • D
    @Component
答案与解析

答案：A

解析：@Value("${key}")读取单个配置项；@ConfigurationProperties批量绑定前缀配置；@Autowired用于依赖注入；@Bean声明Bean；@Component标记组件。

24-单选-10 ★★ M3 MyBatis-Plus

LambdaQueryWrapper相比QueryWrapper的主要优势是（ ）。

24-单选-12 ★ M4 Service与事务

关于@Transactional注解，下列说法错误的是（ ）。

  • A
    默认仅对public方法生效
  • B
    默认只回滚RuntimeException及其子类
  • C
    同一类内的方法直接调用，事务不生效
  • D
    标注在private方法上同样生效
答案与解析

答案：D

24-单选-13 ★★ M4 Service与事务

CTTS中Service层调用多个Mapper写操作，应使用什么保证原子性？

  • A
    synchronized关键字
  • B
    @Transactional
  • C
    @Async
  • D
    数据库锁
答案与解析

答案：B

解析：@Transactional声明式事务保证多操作原子性，任一异常即整体回滚。synchronized是JVM级锁，不适合跨请求/分布式；@Async是异步；数据库锁粒度不当。

24-单选-20 ★★ M6 安全与鉴权

用户密码在数据库中应如何存储最安全？

  • A
    Base64编码
  • B
    MD5加密
  • C
    明文存储
  • D
    BCrypt加盐加密
答案与解析

答案：D

解析：BCrypt自带随机盐且可调工作因子，抗彩虹表与暴力破解。MD5已被证明不安全；Base64是编码非加密；明文最危险。

24-单选-21 ★★★ M6 安全与鉴权

JWT令牌签发后无法主动失效，常见的应对方案是（ ）。

  • A
    改用Session
  • B
    引入RefreshToken + 短有效期 + 黑名单机制
  • C
    增大JWT长度
  • D
    不使用签名
答案与解析

答案：B

解析：JWT无状态特性导致主动失效困难。常见方案：①令牌短有效期（如30分钟）；②RefreshToken刷新；③Redis维护黑名单（登出/封禁时加入）。

24-论述-02 ★★★ M6 安全与鉴权

请论述CTTS项目中JWT鉴权的完整流程，并分析JWT方案的安全风险与应对措施。

答案与评分标准

参考答案要点：

  1. JWT鉴权流程（5分）：

    • 用户登录→校验账号密码→生成JWT（payload含userId、role、exp）→返回前端
    • 前端后续请求携带Authorization: Bearer
    • 拦截器preHandle解析token→校验签名+过期时间→存ThreadLocal→放行
    • 业务层通过ThreadLocalUtil获取当前用户
    • afterCompletion清理ThreadLocal

  2. 安全风险（5分）：

    • 令牌泄露：XSS/中间人截获后可冒用
    • 无法主动失效：签发后服务端无法吊销
    • Payload可解码：明文Base64，敏感信息泄露
    • 重放攻击：令牌有效期内可重复使用
    • 密钥泄露：签名密钥泄露后可伪造任意令牌

  3. 应对措施（5分）：

    • HTTPS传输防中间人
    • 短有效期 + RefreshToken机制
    • Redis黑名单（登出/封禁加入）
    • Payload不存敏感信息
    • 密钥安全管理（环境变量/配置中心）
    • JWT加jti声明 + 一次性校验防重放

评分标准（满分15分）：

  • 流程描述完整（5分）
  • 风险识别全面（5分）
  • 应对措施得当（5分）

24-论述-03 ★★★ M4 Service与事务

请论述Spring声明式事务@Transactional的工作原理、失效场景及使用注意事项。

答案与评分标准

参考答案要点：

  1. 工作原理（4分）：基于Spring AOP动态代理，在方法执行前后通过TransactionInterceptor开启/提交/回滚事务。目标类被代理后，外部调用先经过代理对象，由代理统一管理事务边界。

  2. 失效场景（6分）：

    • 标注在非public方法（private/protected）
    • 同一类内部方法直接调用（this调用，未经代理）
    • 方法内异常被try-catch吞掉，未抛出
    • 默认仅回滚RuntimeException，受检异常默认不回滚（需rollbackFor指定）
    • 数据库引擎不支持事务（如MyISAM）
    • 多线程调用，事务与线程绑定，跨线程失效

  3. 注意事项（5分）：

    • 标注在public方法
    • 跨方法调用通过注入自身代理或AopContext.currentProxy()
    • 显式rollbackFor = Exception.class
    • 大事务拆分，避免长事务持锁
    • 注意传播行为（REQUIRED/REQUIRES_NEW）

评分标准（满分15分）：

  • 原理阐述（4分）
  • 失效场景至少列举4种（6分）
  • 注意事项得当（5分）

// 1. 查询DTO
@Data
public class TaskQueryDTO {
    @Min(value = 1, message = "页码至少1")
    private Integer page = 1;

    @Min(value = 1, message = "每页至少1")
    @Max(value = 100, message = "每页最多100")
    private Integer size = 10;

    private String keyword;
}

// 2. VO
@Data
public class TaskVO {
    private Long id;
    private String title;
    private String description;
    private LocalDateTime deadline;
    private Integer capacity;
    private String teacherName;
}

// 3. 分页结果
@Data
public class PageResult<T> {
    private List<T> records;
    private Long total;
    private Long pages;
}

// 4. Controller
@RestController
@RequestMapping("/tasks")
@RequireRole("STUDENT")
public class TaskQueryController {

    @Autowired
    private TaskService taskService;

    @GetMapping("/page")
    public Result<PageResult<TaskVO>> page(@Valid TaskQueryDTO dto) {
        return Result.success(taskService.queryPage(dto));
    }
}

// 5. Service实现
@Service
public class TaskServiceImpl implements TaskService {

    @Autowired
    private TaskMapper taskMapper;

    @Override
    public PageResult<TaskVO> queryPage(TaskQueryDTO dto) {
        Page<Task> page = new Page<>(dto.getPage(), dto.getSize());
        LambdaQueryWrapper<Task> wrapper = new LambdaQueryWrapper<Task>()
                .like(StringUtils.isNotBlank(dto.getKeyword()), Task::getTitle, dto.getKeyword())
                .gt(Task::getDeadline, LocalDateTime.now())
                .orderByDesc(Task::getCreateTime);
        Page<Task> result = taskMapper.selectPage(page, wrapper);

        PageResult<TaskVO> pr = new PageResult<>();
        pr.setRecords(result.getRecords().stream().map(t -> {
            TaskVO vo = new TaskVO();
            BeanUtils.copyProperties(t, vo);
            return vo;
        }).collect(Collectors.toList()));
        pr.setTotal(result.getTotal());
        pr.setPages(result.getPages());
        return pr;
    }
}

@Mapper
public interface TaskMapper extends BaseMapper<Task> {}

// 7. 单元测试
@SpringBootTest
class TaskServiceImplTest {

    @MockBean
    private TaskMapper taskMapper;

    @Autowired
    private TaskService taskService;

    @Test
    void testQueryPage_Normal() {
        TaskQueryDTO dto = new TaskQueryDTO();
        dto.setPage(1);
        dto.setSize(10);

        Page<Task> mockPage = new Page<>(1, 10);
        mockPage.setTotal(2);
        mockPage.setPages(1);
        List<Task> records = new ArrayList<>();
        Task t = new Task();
        t.setId(1L);
        t.setTitle("Java竞赛");
        records.add(t);
        mockPage.setRecords(records);

        when(taskMapper.selectPage(any(), any())).thenReturn(mockPage);

        PageResult<TaskVO> result = taskService.queryPage(dto);

        assertNotNull(result);
        assertEquals(1, result.getRecords().size());
        assertEquals("Java竞赛", result.getRecords().get(0).getTitle());
        assertEquals(2L, result.getTotal());
    }

    @Test
    void testQueryPage_Empty() {
        TaskQueryDTO dto = new TaskQueryDTO();
        dto.setPage(1);
        dto.setSize(10);

        Page<Task> mockPage = new Page<>(1, 10);
        mockPage.setTotal(0L);
        mockPage.setRecords(Collections.emptyList());

        when(taskMapper.selectPage(any(), any())).thenReturn(mockPage);

        PageResult<TaskVO> result = taskService.queryPage(dto);

        assertNotNull(result);
        assertTrue(result.getRecords().isEmpty());
        assertEquals(0L, result.getTotal());
    }
}
